# XBF3 v0 量化实验报告（M1' 量化实验室）

日期：2026-10-22　机器：本机 CPU（Ryzen AI 9 H 365），纯 numpy 数值实验
代码：`tools/quant/`（`safetensors_reader.py` / `xbf3.py` / `analyze.py`，一键复现 `bash run_v0.sh`）
模型：`models/Ornith-1.5-35B-A3B`（BF16，16 分片，memmap 流式读取，全程未加载完整分片）
原始数据：`tools/quant/results_v0.json`

## 1. 实验设置

- **XBF3 定义**（DESIGN.md §3）：superblock = 256 个沿输入维连续的权重共享 1 个 BF16 scale（0.0625 bpw）；权重 3-bit 补码（level −4..3），8 权重打包 3 字节；合计 3.0625 bpw。
- **量化管线 v0**：可选 Hadamard 旋转（沿输入维的正交变换，推理期融合进前置 RMSNorm/矩阵）→ 逐 superblock 最优 scale 搜索（clip 系数 0.30–1.00，64 点网格，最小化 MSE）→ 3-bit 打包。未做 AWQ/GPTQ 激活校准（v1 计划）。
- **正确性自测**：`unpack3(pack3(q)) == q` 对每个实测张量逐位验证通过；旋转正交性/逆变换在 256/512/768 维验证通过；含离群点的合成数据上旋转把 SNR 从 13.16 dB 提到 14.01 dB。
- **测量对象**（随机种子 42 固定抽样，专家从 256 个中无放回抽 3 个：22 / 167 / 197）：
  - 第 0、20 层各 3 个专家 × gate/up/down（从融合大张量 `experts.gate_up_proj [256,1024,2048]` / `experts.down_proj [256,2048,512]` 切片），共 18 个矩阵；
  - 第 3 层 `self_attn.q_proj`（[8192,2048]，attn_output_gate 使行数翻倍；第 0 层为线性注意力层无 q_proj，故取第一个全注意力层）；
  - `lm_head`（[248320,2048]，等距抽样 4096 行 ≈ 1.65%，控制耗时）。
- **合成激活误差**：对 3 个专家矩阵，256 条 N(0,I) 高斯激活，Y 相对 Frobenius 误差 ‖X(W−Ŵ)ᵀ‖/‖XWᵀ‖。

- 无旋转时的损失集中在少数重尾张量：L0.e197.gate 掉到 11.98 dB（旋转补回 +2.09 dB）。旋转的主要价值不是抬高均值，而是**消灭最坏情况**。

## 3. 逐 superblock 相对误差分布（18 个专家矩阵聚合，各 73728 个 block）

| 分位数 | 无旋转 | 有旋转 |
|---|---|---|
| p50 | 0.198 | 0.195 |
| p90 | 0.225 | 0.216 |
| p99 | 0.337 | 0.237 |
| p99.9 | 0.484 | 0.254 |
| max | **0.570** | **0.300** |
| mean | 0.184 | 0.178 |

旋转把误差尾部砍掉近一半（p99.9: 0.484→0.254，max: 0.570→0.300），证实"superblock 内离群点"是 256 元素大块无 micro-scale 方案的主要误差源，Hadamard 旋转按设计预期消除了它。

附带发现：L0 层 expert 167 的 gate/up 矩阵有超过一半的 superblock 全零（p50 相对误差 = 0 即块范数为 0）——存在近死专家，对 B 档冷热专家分级是利好证据。

## 4. 合成激活输出误差（高斯 X，256 样本）

| 张量 | 无旋转 | 有旋转 |
|---|---|---|
| L0.e22 gate | 0.214 | 0.198 |
| L0.e22 down | 0.199 | 0.198 |

权重域 SNR 差异在输出域被部分平均掉（输出相对误差 ~0.20，对应输出域 SNR ≈ 14 dB，与权重域一致）。注意：真实激活有离群通道，高斯假设会低估无旋转时的输出误差——本项只作下限参考，AWQ 校准实验（v1）必须用真实校准语料。

## 5. 耗时与内存

单个专家矩阵（1M 权重）量化 + 验证 ≈ 0.6 s；q_proj（16.8M 权重）9.7 s；lm_head 4096 行 4.8 s。全量 lm_head（248320 行）外推约 4–5 分钟/遍，可跑但非瓶颈，v0 用抽样替代。全程 memmap，峰值内存 < 1 GB。按此外推，**全模型 35B 参数 CPU 离线量化一遍约 4–6 小时**，通宵任务量级，无需 GPU。

## 6. 结论与判断

1. **实测 SNR 水平**：XBF3 3.0625 bpw 在专家权重上达到 13.78 dB（无旋转）/ 14.05 dB（有旋转）；attention q_proj 与 lm_head 与专家同水平（13.3–13.4 → 14.05–14.06 dB）。这与 llama.cpp Q3_K / IQ3_XXS 档位的公开经验相符。
2. **旋转收益**：均值 +0.27 dB，但真正的价值在尾部——最坏张量 +2.09 dB，block 最大相对误差 0.57→0.30。DESIGN.md"旋转替代 micro-scale"的假设在权重域得到支持：旋转后 block 间误差分布已接近均匀（p99/p50 ≈ 1.22），micro-scale 的边际收益预计有限，可不急于加回 +0.125 bpw。
3. **对"PPL 劣化 <3%"的判断：谨慎乐观，但未证实。** 权重-only 3-bit 在这个 SNR 水平上，对 35B 级 MoE，公开同类结果（Q3_K 档）PPL 劣化通常 <2%；且专家误差对输出的影响还要经过 top-8 路由平均。但本实验有三个未覆盖的风险点，任何一个都可能推翻该判断：
   - **只测了高斯激活**。真实激活的离群通道对 3-bit 是主要杀伤源，attention/lm_head 路径尤其敏感——必须等 v1 的真实校准语料 + AWQ 实验后才能下结论；
   - 未测端到端 PPL / 路由一致性（DESIGN.md §6 的验收门一项都还没跑）；
   - 线性注意力层（占 30/40 层）的量化敏感性完全未测。
4. **下一步（v1）**：接入真实校准分布（imatrix-calibration 语料）、加 AWQ 风格 per-channel 缩放、跑全 lm_head、补线性注意力层张量、小规模端到端 PPL 探针。
